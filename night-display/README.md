# 한밤의 진열장 · 실험 B · [KAI] v0.1.2

신규 독립 게임 프로젝트의 **실험용 최소 모바일 세로 웹 게임**입니다. 정식 게임 선정, 최종 아트, 외부 사람 재미 검증을 뜻하지 않습니다. 기존 게임 저장소·코드·도메인·외부 계정에 의존하지 않습니다.

## 파일
- `index.html`, `styles.css`: 320/360 CSS px 모바일 세로에 대응하는 교체 가능한 임시 화면/단색 에셋
- `engine.mjs`: Rin v0.3 + Dan SYNC 02.1의 순수 결정론적 판정 및 상태 기계
- `app.mjs`: 화면 렌더, 탭→칸/선반 아이템 선택→칸·선택적 드래그, 4단계 반응, 스킵·재배치
- `engine.test.mjs`: Rin의 24행 독립 기대표에 대한 5회 반복(120회), 충돌·중복·스킵·백그라운드·초기화 테스트

## 바로 플레이하기
`play.html`은 같은 엔진/화면을 **단일 HTML**로 묶은 실행본입니다. 파일을 내려받아 데스크톱/모바일 브라우저로 열 수 있으며 별도 서버/설치가 필요하지 않습니다. (일부 보안이 강화된 파일 뷰어는 JavaScript 실행을 차단할 수 있으므로 그런 경우 아래 HTTP 서버 방법을 사용하세요.)

## 실행 / 기능 테스트
Node.js 22가 있으면 프로젝트 폴더에서 다음을 실행합니다.

```sh
npm test
npm run serve
```

브라우저에서 `http://localhost:8000/`으로 접속합니다. `npm run serve`에는 Python 3도 필요합니다. 다른 HTTP 정적 파일 서버도 가능합니다. npm 의존성 설치는 필요 없습니다. 브라우저에서 `file://`로 바로 열면 ES module 보안 정책으로 동작하지 않을 수 있으므로 HTTP 서버로 실행하세요.

## 실험 경계
- 4물건: M 거울, C 촛불, B 종, K 열쇠. 서로 다른 물건을 선반 3칸에 채운 24개 배치만 문 열기 가능.
- 룰 H > R1 > R2 > R3 > R0. H=MCB/BCM, R1=M·C 인접, R2=C·B 인접, R3=B·K 인접. 선반에 없는 물건 인덱스 -1은 인접으로 간주하지 않음.
- 내부 `causeSlots`와 공개 `visibleClueSlots`를 분리. 실제 UI에서 각 반응 첫 공개 강조는 최대 1개, H 가운데 C 1개, R0 없음. 게임의 화면은 숨김 해법/충족 조건 목록을 보여주지 않음.
- R3는 Dan의 최신 콘티: 열쇠 진동 → 종 시선 → 손님이 **원래 존재한 문의 먼지 낀 잠금판을 닦음** → `keyMark`가 드러남. 슬롯 물건은 실제로 움직이지 않음. 별도 에셋으로 교체할 수 있도록 `app.mjs`의 `PRESENTATION`과 스타일로 분리.
- `RESULT`에선 기존 배치·잔여 흔적을 수동 ‘다시 배치’ 전까지 유지. 재배치 버튼 이후 기존 선반 배치 보존. 스킵·브라우저 배경 복귀는 결과를 한 번만 확정.
- 메모리상 QA 이벤트는 브라우저 개발자 도구 `window.__KAI_QA__.events`로 확인. 외부 서버 전송, 사용자 식별, 영구 저장 없음.

## 검증 범위 / 제한
`npm test`는 **엔진 및 상태 기계에 대한 Node 자동 테스트**이며 실제 브라우저 UI/실기기 터치 성능·320/360px 시각 QA나 외부 사람 테스트가 아닙니다. ECHO F01–F10 중 브라우저 입력, 손가락 가림, 무음 시선 인과, 사용자 자발성은 별도의 실제 검증이 필요합니다. 외부 공개 URL·배포 도메인은 제공되지 않습니다.
