# STARPATH POST · 별길 우체국 / 星みち郵便局

Mobile KR/JP original companion route-puzzle. **P1 playable vertical slice; NOT a commercially validated finished game.** The 12-stage standalone HTML build and editable source ZIP are delivered in the originating ChatGPT conversation. GitHub contains decisions, QA evidence, level data, and a compressed standalone HTML recovery copy.

Play: name the companion, tap adjacent tiles on 7×7 floating islands, collect wax seal, pass gate, deliver letter. Optional treat detours change the companion's memory journal and room. No waiting or guilt mechanics. Free hint, undo and restart. Korean/Japanese UI, original SVG drawings, optional synthesized audio, browser-local save with JSON export/import.

The compressed copy index.html.gz.b64 is a lossless backup, NOT a directly playable page. Restore locally via Python base64.b64decode followed by gzip.decompress to obtain index.html.

The full editable source ZIP includes src/index.template.html, src/game.js, src/style.css, src/levels.json, build/build.py, tests/*.py and docs. Native storefront and human player test readiness have NOT been established.
